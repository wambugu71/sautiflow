miniaudiodart Documentation

Cross-platform audio playback package for Dart/Flutter using a native C++ engine (miniaudio + FFI).

Dart FFI C++17 Flutter Plugin Playlist + FX

This document explains architecture, installation, API usage, effects, playlist handling, local/network playback behavior, and troubleshooting.

1) Project Structure

  • audio_engine.cpp/.h — Native playback engine and C ABI exports.
  • lib/audio_engine_ffi.dart — Low-level FFI bindings.
  • lib/src/mini_audio_player.dart — High-level Dart player API.
  • example/lib/main.dart — Example app with playlist, effects, logs, URL/local source input.
  • windows/, linux/, android/ — Platform build integration.

2) Features

Playback Core

  • Play / Pause / Stop
  • Seek by position
  • Track jump / next / previous
  • Gapless next-track handoff

Playlist

  • Set full playlist
  • Add / Insert / Remove
  • Move / reorder
  • Shuffle and loop modes

DSP Effects

  • Gain, Pan
  • 3-band EQ
  • Reverb
  • Low-pass / High-pass / Delay

Observability

  • Polled status stream
  • Native error retrieval
  • Example logs screen
  • Terminal logging in native engine

3) Installation

As Flutter dependency

dependencies:
  miniaudiodart:
    path: ../miniaudiodart
flutter pub get

Native library outputs expected

  • Windows: audio_engine.dll
  • Linux / Android: libaudio_engine.so
  • macOS: libaudio_engine.dylib
  • iOS: linked via process image

4) Quick Start (Dart)

import 'package:miniaudiodart/miniaudiodart.dart';

final player = MiniAudioPlayer();
final ok = player.init(sampleRate: 48000, channels: 2);
if (!ok) {
  throw Exception('Failed to initialize: ${player.getLastError()}');
}

final sources = [
  AudioSource.uri(Uri.file('C:/Music/track1.mp3')),
  AudioSource.uri(Uri.file('C:/Music/track2.mp3')),
];

player.setAudioSources(
  sources,
  initialIndex: 0,
  initialPosition: Duration.zero,
  useLazyPreparation: true,
);

player.play();

5) API Reference (High-level)

Method Description
init({sampleRate, channels}) Create native engine and start polling.
dispose() Release native resources and streams.
setAudioSources(...) Replace entire playlist and move to initial item.
addAudioSource() Append one item.
insertAudioSource(index,...) Insert at index.
removeAudioSourceAt(index) Remove item.
moveAudioSource(from,to) Reorder playlist.
play()/pause()/stop() Playback transport controls.
seekTo(position,{index}) Seek current item, or jump+seek to specific item.
seekToNext()/seekToPrevious() Track navigation.
setLoopMode(mode) off, all, one.
setShuffleModeEnabled(bool) Enable/disable shuffled play order.
status / statusStream Playback state and progress.
getLastError() Latest native engine error.

6) Detailed Examples

A. Local playlist with reorder, loop, shuffle

final player = MiniAudioPlayer();
player.init();

final songs = [
  AudioSource.uri(Uri.file('C:/Music/a.mp3')),
  AudioSource.uri(Uri.file('C:/Music/b.mp3')),
  AudioSource.uri(Uri.file('C:/Music/c.mp3')),
];

player.setAudioSources(songs, initialIndex: 0);
player.setLoopMode(LoopMode.all);
player.setShuffleModeEnabled(true);

player.play();
player.moveAudioSource(2, 1);   // reorder
player.seekToNext();
player.seekToPrevious();

B. Jump and seek to a specific item

// Jump to item index 3 and start at 42 seconds.
player.seekTo(const Duration(seconds: 42), index: 3);

// Seek current track to 10 seconds.
player.seekTo(const Duration(seconds: 10));

C. Effects chain profile (voice-like clarity)

player.setGain(1.15);
player.setPan(0.0);

player.setEqEnabled(true);
player.setEq(low: 0.9, mid: 1.2, high: 1.1);

player.setHighpass(enabled: true, cutoffHz: 90);
player.setLowpass(enabled: true, cutoffHz: 13000);

player.setReverbEnabled(true);
player.setReverb(mix: 0.08, feedback: 0.45, delayMs: 70);

player.setDelay(enabled: false, mix: 0.0, feedback: 0.0, delayMs: 200);

D. Real-time status and error monitoring

final sub = player.statusStream.listen((s) {
  print('playing=${s.isPlaying} index=${s.currentIndex} '
        'pos=${s.positionSeconds.toStringAsFixed(2)} '
        'dur=${s.durationSeconds.toStringAsFixed(2)}');
});

final logSub = player.logStream.listen((line) {
  print('[native] $line');
});

// later
sub.cancel();
logSub.cancel();

E. URL playback behavior by platform

  • Linux/macOS: direct URL source can use native streaming path (if curl is enabled in native build).
  • Windows: current default falls back to download-then-play in the example app.
  • Android: example currently materializes URL to a temp file before playback.
final src = AudioSource.uri(Uri.parse('https://example.com/live.mp3'));
player.setAudioSources([src], initialIndex: 0);
player.play();

8) Troubleshooting

Build errors (Windows + curl headers)

Symptoms: MSVC errors referencing C:\msys64\mingw64\include headers.

Cause: MinGW curl headers selected in an MSVC build. Current project disables auto-curl on Windows plugin builds to avoid this conflict.

App exits / assertions in native engine

Recent fixes replaced unsafe decoder struct copies with pointer-managed decoder lifecycle. Ensure you rebuild native binaries after updates.

Failed host lookup on Android

  • Use a real URL, not placeholders like <link>.
  • Ensure Internet permission exists in app manifest.
  • Validate scheme and host in input parser.

No sound

  • Check player.getLastError() and logs tab in example.
  • Verify file path is valid and exists.
  • Rebuild app so latest native library is bundled.
