Introduction

Most players treat your library like cargo. Sautiplay treats it like a signal chain. Under the hood runs Sautiflow, a custom audio engine built on miniaudio, libsoxr, and libsamplerate — the same architecture whether you're on a phone or a desktop tower.

The result is a player that resamples without pitch artifacts, seeks without stutters, and switches DAC sample rates mid-session without dropping a frame. No ads, no accounts, no telemetry. Your files, your network, your hardware.

Sautiplay is developed in the open. Every release is built by public CI from tagged source, so what you install is what you can audit.

Feature Specification

Grouped by subsystem. All DSP operates in real time with live parameter updates — no playback interruption.

F/01 — SIGNAL PATH

  • Auto Bit-Perfect mode with exclusive-mode MMAP & low-latency profiles
  • Hardware sample-rate matching; auto rate-switch for DACs
  • Loudness normalization to BS.1770-4 LUFS + true-peak limiter
  • Full-scale TPDF dithering, plugin delay compensation

F/02 — DSP SUITE

  • 3-band & multiband parametric equalizers with live graphs
  • Crossfeed & Ambiophonics R.A.C.E. with soundstage view
  • Convolver (impulse responses), DDC, reverb, delay, stereo widen
  • Polarity invert, L/R swap, per-channel gain; AutoEQ import

F/03 — SOURCES & STREAMING

  • YouTube Music search, streaming & playlist import
  • DLNA cast-out plus built-in DLNA receiver (MediaRenderer)
  • FTP browsing, direct URL streams, disk-cached online playback
  • Last.fm scrobbling with persistent sign-in

F/04 — LIBRARY & UX

  • Gapless playback, loudness-aware crossfade, A-B repeat loop
  • Material 3 Expressive interface with dynamic theming
  • Lyrics view, M3U playlists, dedupe by file-content hash
  • Desktop system tray, native notifications, waveform extraction
